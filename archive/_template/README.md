# 新しい作品のひな形

1. このフォルダーを `archive/` 内へコピーし、例として `my-new-work` に改名します。
2. 画像・動画をコピー先へ入れます。
3. `work.js` の作品名・カテゴリ・短い概要・素材ファイル名を編集します。
4. `content.md` に詳しい本文を書きます。本文が不要なら `work.js` の `content: 'content.md'` 行を削除します。
5. `archive/index.js` の配列に `'my-new-work',` を追加します。
6. サイト直下で `node scripts/preview.mjs` を実行し、[プレビュー](http://127.0.0.1:4173/)で確認します。
7. 公開前に `node scripts/check.mjs` を実行し、カテゴリ設定・作品情報・素材・本文ファイルを確認します。

## どのファイルを編集するか

| ファイル | 編集する内容 |
| --- | --- |
| `work.js` | 作品名、カテゴリ、短い概要、年度、一覧画像・主画像・動画の指定 |
| `../categories.js` | サイト共通のカテゴリID・表示名・並び順 |
| `content.md` | 見出し、段落、追加画像、リンクなどの詳しい本文 |
| `thumbnail.svg` / `image.svg` | 仮の画像。自分の素材へ置き換え、名前を変えた場合は参照も更新 |

## カテゴリを指定する

`work.js` の `category` には、`archive/categories.js` に登録したIDを指定します。
新しいカテゴリを使う場合は、まず `archive/categories.js` の配列へ追加します。

```js
{ id: 'animation', name: 'Animation' },
```

次に作品の `work.js` を変更します。

```js
category: 'animation',
```

一覧のボタンは自動で追加されます。表示名を日本語にすることもできます。
IDには半角英小文字・数字を使い、単語の区切りはハイフンにします。重複したIDと `all` は使えません。

詳細ページの「Category」には、通常は登録カテゴリの `name` が表示されます。
作品だけ別の名称にしたい場合は、`label: 'Motion graphics'` のように指定します。
`label` が未指定または空欄なら、カテゴリ名が使われます。
カテゴリは写真・動画の表示方法とは独立しているため、任意のカテゴリで `video` や `youtube` を使えます。

## 本文と画像を編集する

Markdown内の画像や相対リンクは、その `content.md` があるフォルダーを基準にします。
同じ場所の画像は `![画像の説明](image.jpg)` と書けます。
本文にHTMLや `iframe` を書いても解釈されません。動画の表示には `work.js` の `video` または `youtube` を使います。

HTMLを直接開く `file://` ではMarkdown本文を読み込めないため、ローカルサーバーで確認してください。
公開後のGitHub Pagesでも本文を表示できます。ビルドは不要です。

この `_template` 自体は一覧に表示されません。
フォルダー名は半角小文字・数字・ハイフンを使います。
一度公開したフォルダー名を変えると、作品詳細のURLも変わります。
詳しい記法例と更新手順はサイト直下の [README.md](../../README.md) を参照してください。
